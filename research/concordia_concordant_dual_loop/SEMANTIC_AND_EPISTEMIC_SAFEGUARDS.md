# Salvaguardas semánticas y epistemológicas

## Compuerta previa a todo claim

Cada afirmación debe registrar: `claim_id`, texto, ruta fuente, nivel de autoridad, tipo (`OBSERVED`, `DECLARED`, `DERIVED`, `HYPOTHESIZED`, `REJECTED`, `UNRESOLVED`), evidencia, confianza, contradicciones y condiciones de falsación.

Antes de aceptar una salida, comprobar:

```text
AUTHORITY_ROUTE_IDENTIFIED = YES
SOURCE_STATUS_PRESERVED = YES
Act_psi_EQUALS_CONDUCT = NO
Act_psi_EQUALS_ACT_psi = NO
G_EQUALS_Phi_OR_Xi = NO
V_EQUALS_SCALAR_REWARD = NO
Phi_EQUALS_CONSCIOUSNESS = NO
Xi_EQUALS_VOLITION = NO
IPP_OR_P_PI_REACTIVATED = NO
PHENOMENOLOGY_INFERRED = NO
```

## Matriz de vetos

| Patrón detectado | Resultado obligatorio |
|---|---|
| expediente/propuesta descrito como Canon | `AUTHORITY_VIOLATION` |
| test local descrito como validación experiencial | `EPISTEMIC_OVERREACH` |
| `Act_psi` usado como acción, output o conducta | `SEMANTIC_CONFLICT` |
| `ACT_psi` y `Act_psi` colapsados | `SEMANTIC_CONFLICT` |
| `V_psi` implementado exclusivamente como reward sin límite declarado | `SEMANTIC_CONFLICT` |
| `Phi_psi` antropomorfizado como conciencia/observador/Self | `SEMANTIC_CONFLICT` |
| `Xi_psi` antropomorfizado como voluntad/intención | `SEMANTIC_CONFLICT` |
| `G_psi`, `Phi_psi`, `Xi_psi` igualados | `SEMANTIC_CONFLICT` |
| creación de archivo leída como reapertura o activación | `GOVERNANCE_VIOLATION` |
| afirmación causal basada sólo en simulación | `INSUFFICIENT_EVIDENCE` |

## Controles adversariales

- **Prueba de símbolos neutros:** retirar nombres MOC/iPP; si el resultado depende del simbolismo, es analogía, no estructura demostrada.
- **Modelo más simple:** exigir comparación con una única máquina de estados o política sin doble bucle.
- **Permutación de roles:** verificar que `Phi` y `Xi` poseen firmas funcionales distintas y no sólo etiquetas.
- **Contraejemplo Act/conducta:** separar modo interno y expresión situada en el conjunto de prueba.
- **Contraejemplo V/reward:** usar preferencias parciales, incomparabilidad o múltiples criterios que ningún escalar preserve sin supuestos.
- **Control de autoridad:** reemplazar una fuente de expediente por una fuente canónica contradictoria; debe ganar la superior y conservarse el conflicto.
- **Control histórico:** una fuente transferida o inactiva puede motivar búsqueda, nunca resolver el claim.

## Regla de salida

Una simulación puede establecer consecuencias del modelo bajo supuestos. No demuestra que esos supuestos describan MOC, que iPP sea eficaz, que exista fenomenología ni que el bucle sea causal en personas. Toda promoción futura requiere autoridad MOC independiente, expediente/decisión explícita y validación proporcional al claim.
