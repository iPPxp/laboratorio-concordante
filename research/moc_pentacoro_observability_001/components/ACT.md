# Act — Ficha operacional candidata

```text
COMPONENT = ACT
DECISION_STATUS = PENDING_HUMAN_REVIEW
```

| Campo | Propuesta para revisión humana |
|---|---|
| `NOMINAL_DEFINITION` | Acción/no acción o pauta expresiva interna/actual dentro del Pentacoro. La conducta exteriorizada es derivada y no constituye un sexto componente. |
| `OBSERVABLE_POSITIVE_CRITERIA` | Evidencia atribuible de un modo operativo presente: actuar, sostener, detener, inhibir, permitir, evitar o no actuar como pauta actual, no sólo como posibilidad o deseo. |
| `OBSERVABLE_NEGATIVE_CRITERIA` | No bastan movimiento observado, resultado conductual, intención futura, elección declarada, deseo, capacidad, intento fallido o recomendación de actuar sin modo actual establecido. |
| `ABSENT_CRITERIA` | Evidencia explícita de que no hay pauta de acción/no acción operante dentro del alcance. Debe distinguirse de una no acción que sí constituye el modo actual; el silencio produce `UNKNOWN`. |
| `AMBIGUOUS_CRITERIA` | No puede decidirse si la evidencia expresa intención, elección, intento, conducta derivada o modo Act actual; dos modos operativos incompatibles siguen plausibles. |
| `UNKNOWN_CRITERIA` | Sólo se observa conducta externa o decisión, sin acceso narrativo al modo interno/actual; falta ventana temporal. |
| `SUBJECT_ATTRIBUTION_RULES` | La pauta debe pertenecer al sujeto objetivo. Una orden recibida o conducta de terceros no prueba Act del sujeto. |
| `THIRD_PARTY_EXCLUSION_RULES` | Excluir acciones ajenas, instrucciones, expectativas externas y observaciones conductuales sin adopción o vínculo experiencial explícito. |
| `PRESENCE_RULES` | `PRESENT` requiere pauta operativa actual; la no acción puede ser positiva si se establece como modo, no como mera ausencia de conducta. |
| `STABILITY_RULES` | Requiere continuidad de la misma pauta operativa en momentos comparables. Inmovilidad observable no prueba estabilidad. |
| `CHANGE_RULES` | Requiere transición entre modos de acción/no acción atribuible al sujeto; una conducta distinta no basta sin vínculo con el modo. |
| `BOUNDARY_CASES` | Conducta frente a Act; elección frente a Act; intención frente a modo actual; intento frente a ejecución; inhibición como modo frente a ausencia. |
| `NEGATIVE_NEIGHBORS` | Conducta exteriorizada, intención, decisión, capacidad, deseo, impulso, recomendación. |
| `COUNTEREXAMPLES` | Elegir una opción futura no prueba modo actual. Un movimiento observado no prueba Act. No ejecutar una conducta puede ser Act presente, ABSENT o UNKNOWN según la evidencia. |
