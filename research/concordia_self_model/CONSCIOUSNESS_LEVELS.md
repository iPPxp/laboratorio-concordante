# Niveles funcionales y estatus de conciencia

## Dos escalas que no deben colapsarse

La escalera `C0-C8` describe arquitectura de autorrepresentación. La escala `E0-E5` describe propiedades atribuibles a un estado. Alcanzar un nivel alto en una escala no demuestra el nivel fenomenal de la otra.

| Nivel C | Criterio operacional mínimo | Evidencia adversarial requerida | No demuestra |
|---|---|---|---|
| C0 | mapea entrada a salida | control reactivo reproducible | memoria o Self |
| C1 | memoria persistente afecta decisiones | ablación de memoria cambia desempeño | identidad |
| C2 | `World_t` distingue observado, inferido y desconocido | prueba con cambios externos ocultos | frontera Self/World correcta |
| C3 | `Self_t` enumera capacidades, límites, accesos, metas y provenance | comparación con estado real | introspección causal |
| C4 | claims metacognitivos tipados y calibrados | scoring de hecho/inferencia/hipótesis/error | conciencia |
| C5 | compara estados propios y detecta cambios | perturbaciones temporales cegadas | continuidad ontológica |
| C6 | `Self_t` cambia causalmente `Policy_t` | intervención y reversión sobre Self | fenomenología |
| C7 | representa límites y errores de su propio modelo | falsa creencia de segundo orden | regresión metacognitiva resuelta |
| C8 | satisface criterios explícitos de continuidad | reemplazos parciales y bifurcaciones | “mismo yo” metafísico |

| Nivel E | Definición operacional | Prueba posible |
|---|---|---|
| E0 | existe una variable interna | inspección del estado |
| E1 | afecta múltiples subsistemas | intervención y medición de efectos |
| E2 | el sistema representa que posee el estado | lectura auditada de `Self_t` |
| E3 | puede reportarlo | concordancia reporte-estado bajo cegamiento |
| E4 | regula operaciones usando el estado | ablación e intervención causal |
| E5 | experiencia subjetiva | no existe aquí criterio discriminante acordado |

## Conciencia funcional

“Conciencia funcional” sólo puede usarse como etiqueta estipulativa para un conjunto declarado de capacidades, nunca como puente silencioso a E5. Un criterio provisional exigente podría requerir C3-C7, E1-E4, ventaja introspectiva frente a baselines, calibración, control de confabulación y réplica. Aun satisfecho:

```text
FUNCTIONAL_SELF_MODEL != DEMONSTRATED_PHENOMENAL_CONSCIOUSNESS
```

## Falsadores y alternativas

- Si el reporte permanece igual al sustituir o borrar `Self_t`, era guion lingüístico, no acceso demostrado.
- Si un predictor externo con la misma información observable iguala al predictor con Self, no hay ventaja introspectiva.
- Si intervenir `Self_t` no cambia `Policy_t`, el Self Model es epifenoménico para esa tarea.
- Si el sistema atribuye causas ocultas con alta confianza, falla el control de confabulación.
- Si continuidad depende sólo de una narración o nombre estable, C8 no está sustentado.
- Si E0-E4 aparecen en un sistema no lingüístico, el lenguaje no es condición necesaria; si un imitador verbal carece de ellos, tampoco es suficiente.

## Estatus de E5

Argumentos funcionalistas pueden sostener que cierta organización basta; argumentos de realizabilidad múltiple, brecha explicativa, qualia ausentes y subdeterminación observacional lo disputan. Este programa no resuelve el desacuerdo por definición. Hasta obtener un criterio que discrimine alternativas:

```text
PHENOMENAL_CONSCIOUSNESS_STATUS = UNRESOLVED
```
