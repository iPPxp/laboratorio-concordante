# Expedientes

Esta carpeta contiene investigacion activa, congelada o cerrada.

La entrada a un frente debe hacerse por su expediente padre, no por orden
alfabético. Para los frentes abiertos vigentes:

- `MOC-001.md`;
- `AO-001.md`;
- `TCS-001.md`.

El mapa transversal vigente está en
`05_Estado_Proyecto/MAPA_COHERENCIA_2026-09-12.md`.

Un expediente debe tener:

- identificador
- estatus
- proposito
- fuentes relevantes
- hipotesis afectadas
- problemas abiertos relacionados
- decisiones asociadas
- criterio de cierre

## Estatus posibles

- abierto
- cerrado
- congelado
- rechazado
- absorbido
