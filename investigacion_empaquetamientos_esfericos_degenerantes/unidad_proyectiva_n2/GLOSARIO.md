# Glosario formal

| Término | Definición en este estudio | Exclusión |
|---|---|---|
| Origen | Punto (0\in\mathbb R^3\) | No es una dirección ni fuente por sí mismo |
| Representante | (u\in S^2\) elegido para una clase | No es el objeto proyectivo completo |
| Antípoda | Punto \(-u\) de (u\) | No implica fuerza o energía contraria |
| Dirección proyectiva | Clase \([u]=\{u,-u\}\) | No tiene cabeza o signo intrínseco |
| Recta no orientada | Subespacio (L_{[u]}=\{tu\}\) | No es un rayo orientado |
| Polar | Estado donde (u\) y \(-u\) son físicamente distinguibles | No equivale a apolar |
| Apolar | Estado invariante bajo (u\mapsto -u\) | No significa ausencia de estructura |
| Observador coordenado | Elección de marco o signo | No interactúa físicamente por definición |
| Observador instrumental | Aparato con acoplamiento definido | No puede postularse sin dinámica |
| Fuente | Término de una ley dinámica o de campo | No es sinónimo de centro geométrico |
| Energía | Funcional escalar con dominio y unidades | No es una dirección o una etiqueta |
| Emergencia relacional | Propiedad dependiente de relaciones no reducible a términos unarios | No implica emergencia fuerte |
| Emergencia fuerte | Información global no reconstruible aun con los datos inferiores completos | No se acredita en este modelo |
| Espacio de estados | Conjunto abstracto de estados posibles | No es automáticamente dimensión espacial física |
| Sección | Elección de un representante sobre cada punto del cociente | Puede existir localmente y fallar globalmente |
| Tensor (Q) | (s(u\otimes u-I/3)), invariante por cambio de signo | No codifica una polaridad orientada |

## Relaciones tipadas

```text
u ∈ S²
[u] ∈ RP²
π(u) = [u]
π^{-1}([u]) = {u,-u}
0 ∈ L_[u]
L_[u] ∩ S² = {u,-u}
```

No se usa una igualdad entre objetos de tipos distintos.
